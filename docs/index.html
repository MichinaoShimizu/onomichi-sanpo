クレジット

データ

地形・空中写真・地図は国土地理院の標高タイル・シームレス空中写真・ベクトルタイルを加工して作成しました。名所の解説と、地理院の注記にない名所の位置は概略です。

表現について

建物の質感や人・車・樹木などは、すべてプログラムで生成した一般的な表現です。実在の人物・店舗・看板・車両を再現したものではありません。

プライバシー

このゲームは個人情報を集めません。設定と進行状況はこのブラウザの中にだけ保存され、外部への送信やアクセス解析は行いません。
